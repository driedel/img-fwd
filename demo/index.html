img-fwd

Transparent image optimization — zero changes to your URLs

Zero Cost Open Source Production Ready
View on GitHub Docker Hub

How It Works

No URL changes. No code changes. Just add query parameters.

Browser
→
img-fwd
proxy
→
imgproxy
transform
↔
Your Origin
images
Original: https://example.com/images/photo.jpg
Optimized (same URL!): https://example.com/images/photo.jpg?rs=800

The proxy intercepts requests with transformation params and returns optimized images automatically.

Resize & Compression

Add ?rs=width to any image. The proxy returns the perfect size.

Force WebP format

Quality & Effects

Fine-tune output with quality, blur, and crop parameters.

Quality Control

?q=90&rs=600 Near lossless
?q=75&rs=600 Balanced (recommended)
?q=50&rs=600 Maximum compression

Blur Effects

?blur=2&rs=600 Subtle
?blur=5&rs=600 Medium
?blur=10&rs=600 Heavy

Smart Crop

?g=sm&rs=400:300 Smart gravity
?g=ce&rs=400:300 Center gravity
?g=no&rs=400:300 North gravity

Supported Parameters

Param Description Example Result
f Output format ?f=avif, ?f=webp Force AVIF or WebP
rs Resize width or width:height ?rs=800, ?rs=800:600 Fit to dimensions
g Gravity (crop focal point) ?g=sm, ?g=ce Smart or center crop
q Quality 1-100 ?q=80 Compression level
blur Blur intensity ?blur=5 Gaussian blur

Non-transformation params (e.g., ?v=2) are forwarded to the origin URL.

Usage

In your HTML

<!-- Original -->
<img src="https://example.com/images/photo.jpg">

<!-- Optimized via img-fwd -->
<!-- Just add ?rs=width — same URL! -->
<img src="https://example.com/images/photo.jpg?rs=800">

<!-- Auto-format: .jpg becomes AVIF automatically -->
<img src="https://example.com/images/photo.jpg?rs=600">

With Docker

docker run -d \
  -p 8888:8888 \
  -e ALLOWED_ORIGINS=example.com \
  -e SOURCE_BASE_URL=https://your-origin.com \
  driedel/img-fwd:latest
